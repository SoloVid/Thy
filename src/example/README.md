# Thy Examples

It's still a bit of a WIP how I'm managing Thy examples and test samples.

taken from the language spec document.
They're not 100% the same, but I'm at least trying to pick
stuff for starters from there.

I'll need to decide at some point if I want 100% overlap
or maintain parity manually.

I'm also not sure how I want to handle error cases.
Maybe error cases should live right alongside the good examples,
or maybe they should be quarantined somehow.
